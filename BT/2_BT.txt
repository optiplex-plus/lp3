1. Solidity program
The smart contract allows you to:

Create student records using a struct.

Store multiple students using an array.

Add student data.

Display an individual student's details.

Display all students.

Observe gas consumption when transactions are executed.


 // SPDX-License-Identifier: MIT
pragma solidity 0.8.38;

contract StudentData {

    // Structure to store student information
    struct Student {
        uint rollNo;
        string name;
        uint age;
        string department;
    }

    // Array to store multiple students
    Student[] public students;

    // Add a new student
    function addStudent(
        uint _rollNo,
        string memory _name,
        uint _age,
        string memory _department
    ) public {
        students.push(Student(_rollNo, _name, _age, _department));
    }

    // Get total number of students
    function getStudentCount() public view returns (uint) {
        return students.length;
    }

    // Get details of a particular student
    function getStudent(uint index)
        public
        view
        returns (uint, string memory, uint, string memory)
    {
        Student memory s = students[index];
        return (s.rollNo, s.name, s.age, s.department);
    }
}

Note: pragma solidity 0.8.38; requires the exact compiler version. If Remix does not load it, choose the exact version from the compiler dropdown or use pragma solidity ^0.8.0; with an available 0.8.x compiler.

9. Viva Questions
1. What is a structure in Solidity?
A structure (struct) is a user-defined data type used to group multiple related variables.

2. What is an array in Solidity?
An array stores multiple elements of the same data type or structure.

3. What is gas in Ethereum?
Gas is the computational unit used to measure the resources required to execute operations on Ethereum.

4. Why does adding a student consume gas?
Adding a student modifies blockchain storage, requiring computational resources.

5. What is the difference between view and public?
view functions read data without modifying blockchain state. public specifies that a function can be called externally and internally.

6. Why is blockchain data difficult to modify?
Blockchain records are protected by cryptographic mechanisms and consensus, making historical data tampering difficult.
