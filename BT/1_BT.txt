Blockchain Technology Practical: Bank Account Smart Contract
Aim: To write and deploy a Solidity smart contract on a test network that performs the following banking operations:

Deposit money

Withdraw money

Show account balance

We'll use Remix IDE with Solidity compiler version 0.8.38 and deploy the contract on a test network.

1. Smart Contract Code
Open Remix IDE: Remix IDE

Create a new file named BankAccount.sol.

Paste the following code:


 // SPDX-License-Identifier: MIT
pragma solidity ^0.8.38;

contract BankAccount {

    address public owner;

    // Set the owner when the contract is deployed
    constructor() {
        owner = msg.sender;
    }

    // Deposit money into the bank account
    function deposit() public payable {
        require(msg.value > 0, "Deposit amount must be greater than zero");
    }

    // Withdraw money from the bank account
    function withdraw(uint amount) public {
        require(msg.sender == owner, "Only account owner can withdraw");
        require(amount > 0, "Amount must be greater than zero");
        require(amount <= address(this).balance, "Insufficient balance");

        payable(owner).transfer(amount);
    }

    // Show the current balance of the bank account
    function showBalance() public view returns (uint) {
        return address(this).balance;
    }
}

Component

Description

pragma solidity ^0.8.38

Specifies the Solidity compiler version.

address public owner

Stores the address of the customer/account owner.

constructor()

Sets the deployer as the account owner.

deposit()

Accepts Ether using payable.

msg.value

Amount of Ether sent with the transaction, in Wei.

withdraw(uint amount)

Withdraws the specified amount of Ether.

require()

Checks conditions and prevents invalid operations.

address(this).balance

Returns the Ether balance stored in the contract.

showBalance()

Displays the current contract balance.

Important: Solidity stores Ether amounts in Wei.
1 Ether = 10¹⁸ Wei

8. Important Viva Questions
Q1. What is a smart contract?
A smart contract is a self-executing program stored on a blockchain that automatically performs operations when predefined conditions are met.

Q2. What is Solidity?
Solidity is a high-level programming language used to develop smart contracts on Ethereum-compatible blockchains.

Q3. What is Ether?
Ether (ETH) is the native cryptocurrency of the Ethereum blockchain.

Q4. What is msg.value?
It represents the amount of Ether sent with the current transaction, measured in Wei.

Q5. What is payable?
The payable keyword allows a function to receive Ether.

Q6. What is require()?
It checks a condition and reverts the transaction if the condition is false.

Q7. What is a test network?
A test network is a blockchain environment used for development and testing without using real cryptocurrency.

Q8. What is Remix IDE?
Remix is a browser-based IDE used to write, compile, deploy, and test Solidity smart contracts.
